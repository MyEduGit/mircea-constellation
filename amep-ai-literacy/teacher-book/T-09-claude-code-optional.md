## T-9.1 · Teacher Background

### What is Claude Code?

Claude Code is a command-line interface (CLI) tool that allows developers to interact
with Claude directly from the terminal — the text-based window used by programmers.
Unlike the web chat interface, Claude Code can:

- Read files on the developer's computer.
- Run code.
- Suggest edits to existing code files.
- Automate repetitive programming tasks.

**Is this relevant to AMEP students?**

For most AMEP classes: **no.** This module is flagged as optional and is only appropriate
for students in an IT or digital skills stream who are learning to code.

For those students, Claude Code is genuinely transformative — it can accelerate
their learning by explaining errors in real time, suggesting fixes, and providing
worked examples.

**What teachers need to know (not do):**

You do not need to be a programmer to teach this module.
The module's goal is *awareness*, not competency.
Students should leave understanding:
1. What Claude Code is.
2. That it is a tool for people who write computer programs.
3. One concrete example of how it helps (finding an error).

If you have IT-stream students who already code, they will likely know more than you
about this topic. Embrace that. Let them lead the demonstration.

**Claude Code installation (for teacher reference only):**

Claude Code requires Node.js installed on a computer and is run via the terminal.
It is not a browser tool. It is not available on phones.
If students want to install it, direct them to: **docs.anthropic.com/claude-code** ⏱

## T-9.4 · Scripts

### For non-IT classes

> "Before we move to our final module, I want to show you one more thing Claude can do.
> This is called Claude Code.
> It is for people who write computer programs.
> You do not need to know how to code to understand this.
> I just want you to see that AI can also help with technical work.
>
> Let us look at an example together."

---

### After reading the Rustam dialogue

> "Did you notice what Claude did?
> Rustam made a small mistake — a capital letter in the wrong place.
> Claude found it immediately. It explained what was wrong and showed the fix.
>
> For people learning to code, this is very useful.
> Finding errors by yourself can take a long time.
> Claude finds them in seconds.
>
> But Claude is not always right. Like we have said in every lesson:
> you always check. You always test the code."

---

### For IT-stream students who are already coding

> "Some of you are already learning Python or another language.
> Claude Code is something you can use in your own study.
> After class, I will share the link to the Claude Code documentation.
> You can explore it at home.
> If you have questions, bring them to class next week."

## T-9.5 · Differentiation

This module is not differentiated by CEFR level — it is differentiated by whether students have coding knowledge.

| Student type | Activity |
|-------------|----------|
| No coding experience | Read the dialogue. Understand the concept. Discuss who needs this tool. |
| Beginner coder (e.g., currently learning Python) | Complete S-9.6. Ask Claude about the error. Write their own one-line code and ask Claude to check it. |
| Experienced coder | Lead the class demonstration. Use their own real code for the error-finding activity. |

## T-9.6 · Common Student Questions and Model Answers

**Q1: "Do I need to be a good programmer to use Claude Code?"**
> "No — beginners benefit most from it.
> When you are learning, you make many small errors.
> Claude helps you understand what went wrong and why.
> As you improve, Claude helps you with more complex tasks."

**Q2: "Can Claude write a whole program for me?"**
> "Yes, for simple programs.
> But if you are learning to code, you should write first and use Claude to check.
> If Claude writes everything, you learn nothing.
> Use Claude the way you would use a dictionary — when you are stuck, not instead of trying."

**Q3: "What programming languages does Claude know?"**
> "Claude knows most common languages: Python, JavaScript, HTML, CSS, Java, SQL, and others.
> Python is the most commonly used in beginner courses and Claude handles it very well."

**Q4: "Is Claude Code free?"**
> "Claude Code requires a paid Anthropic account. ⏱
> Check the current pricing at anthropic.com before committing to it."

**Q5: "Can I use Claude in my coding assignment at TAFE?"**
> "Check your TAFE's rules about AI tools first.
> Many TAFE programs allow AI as a study aid but require you to write and understand your own code.
> Declare your use of AI if your teacher asks. Honesty is always the right choice."

## T-9.7 · Things That Will Go Wrong

| Problem | What to do |
|---------|------------|
| No students have any coding experience | Run the 30-minute awareness version. Focus on: what is code, what is an error, how does AI help. |
| One student knows much more than you | Embrace it. Ask them to explain to the class. Say: "You are the expert here today." |
| Students want to install Claude Code in class | Note: installation takes time and requires admin permissions on some computers. Defer to homework. |
| The Python code example confuses students | Say: "You do not need to understand the code itself. Focus on this: Claude found the mistake. That is the important idea." |
