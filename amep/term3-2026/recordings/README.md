# READ ME — VU23525 recording transcripts (LLM handoff package)

Two self-contained transcript files for the Certificate III (22640VIC) unit VU23525
assessment recordings used in the AMEP Term 3 2026 evening classes (CP123E3 & CP123E4):

1. `VU23525_TaskA_Eating_for_good_health_TRANSCRIPT.md` — listening Task A (2:31 MP3)
2. `VU23525_TaskC_Listen_to_instructions_TRANSCRIPT.md` — listening Task C (2:24 MP4),
   recording nicknamed "A heavy load" (safe lifting)

Each file carries: full provenance (qualification/unit/assessment tool/version/licence),
media technical details, the official conduct protocol, where each recording sits in the
ten-week Term 3 2026 lesson-plan set, a verification statement (script ↔ machine ASR ↔
human transcript triangulation), and the verbatim official transcript.

Related artefacts in this repository:
- `amep/term3-2026/session-plans/` — the ten verified weekly plans (see its README)
- `amep/term3-2026/backup/` — timestamped zip of the full plan set + SHA256SUMS
- `tools/asr_verify.py` — the offline ASR script used for the audio verification

The media files themselves are NOT in this repository (assessment bank materials); they
live in the teacher's commUnity+ assessment folders and the Claude session uploads.
