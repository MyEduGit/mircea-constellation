# AMEP Term 3 2026 — Worksheets & Speaking Packs (CP123E3 & CP123E4)

Engaging, tiered classroom materials for the mixed Cert I / II / III EAL
evening class. Everything is talking- and activity-based, with clear
one-instruction-per-task design and a ⭐ / ⭐⭐ / ⭐⭐⭐ tier key so all
levels do the same lesson at their own depth.

## Folders

### `weekly/` — tiered student worksheets, Weeks 1–10
One Word file per week. Each has a Table of Contents (page 1) + page
numbers, then:
- **Part A** full vocabulary list for that week's theme (topic tables)
- **Part B** regular verbs (base → +ed → meaning)
- **Part C** irregular verbs (base → special past → meaning)
- **Parts D–F** separated, tiered exercises for vocabulary, regular verbs
  and irregular verbs
- **Part G** that week's language (speaking/listening tasks), tiered
- **Teacher answer key** (last page — remove before copying)

Weekly themes follow the lesson plans: W1 introductions & travel · W2
travel conversations & clarification · W3 food, menus & money · W4 healthy
choices & free activities · W5 revision/assessment week · W6 short talks ·
W7 first aid & safe lifting · W8 instructions & the pizza transaction ·
W9 feedback & consolidation · W10 whole-term revision & celebration.

### `speaking-packs/` — combined talking/pair-game packs
Four Word files, each with a TOC + page numbers, bundling a PRACTICE
(parallel) text to use **before** the assessment and the REAL text for
**after** (consolidation), plus optional Cert III grammar sheets:
- `ENGAGE_Tour_Melbourne_and_West_COMBINED.docx` (Cert II Task A)
- `ENGAGE_FirstAid_Cut_and_Burn_COMBINED.docx` (Cert II Task C)
- `ENGAGE_CertIII_Health_Eating_and_Sleep_COMBINED.docx` (Cert III Task A)
- `ENGAGE_CertIII_Instructions_Lifting_and_Mopping_COMBINED.docx` (Cert III Task C)
- `ENGAGE_CertI_Travel_Roleplay_COMBINED.docx` (Cert I VU23501 Task A — travel role-play)
- `ENGAGE_CertI_Ordering_Roleplay_COMBINED.docx` (Cert I VU23501 Task B — ordering role-play)
Different games per genre (mingle / info-gap / role-play; sequencing race;
survey / rank & talk / advice; "Do it!" TPR / spot-the-mistake).

### `archive/` — earlier gap-fill worksheet drafts (superseded)
Kept for reference only; replaced by the engaging materials above.
