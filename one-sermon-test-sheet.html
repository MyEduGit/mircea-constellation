3. The corrected test (this one really works)

The old test was wrong: it asked Claude Code to transcribe by itself, which it cannot do. The right way uses ScribeClaw, which you already have.

Open Claude Code and type these words:

TYPE THIS
Use my ScribeClaw pipeline to transcribe one sermon.
1. First check ScribeClaw is running (docker logs scribeclaw).
2. Here is the sermon video: [drag the file in].
3. Run the whole pipeline and show me the text file.
Do NOT upload anything to YouTube — just make the transcript and show me.

Then watch what happens:

  • If you get a transcript → your own pipeline works. 🎉 You needed nothing new.
  • If it says ScribeClaw isn't running, or needs a key → that is the real thing to fix (see the next box).

4. What actually gets you stuck

It is almost never missing software. It is a missing key or login:

  • AssemblyAI needs an API key (for one of the transcribe options).
  • YouTube upload needs a one-time Google login.
  • ClickUp / Slack / n8n need you to be logged in — this is the same wall Codex kept hitting.

Fixing one of these logins is usually what unblocks everything else.

5. Remember

  • Don't buy Hermes or KiloClaw — you already have more than they offer.
  • The blocker is usually a login or key, not new software.
